# Institute for Study of Rights and Repression (ISRR)

Website for the Institute for Study of Rights and Repression at the University of New Mexico, Department of Political Science.

**Directors:** Loren Collingwood & Sarah Dreier

## Setup

This is a static HTML/CSS site designed to be hosted on [GitHub Pages](https://pages.github.com/).

### To deploy:

1. Push this repository to GitHub
2. Go to repository **Settings** > **Pages**
3. Under "Source," select **Deploy from a branch**
4. Select the `main` branch and `/ (root)` folder
5. The site will be live at `https://<username>.github.io/isrr-website/`

### To add photos:

Place headshot images in the `images/` directory:
- `images/collingwood.jpg` — Loren Collingwood headshot
- `images/dreier.jpg` — Sarah Dreier headshot
- Student photos as needed

### To add graduate students:

Edit `people.html` and replace the placeholder student cards with actual names, photos, and research areas.
